## 🎬 مقدمه

**برنامه خوشه‌بندی چهره** یک برنامه وب کاملاً آفلاین است که روی localhost اجرا می‌شود. این برنامه از مدل‌های پیشرفته یادگیری عمیق برای تشخیص چهره در تصاویر آپلود شده، استخراج بردارهای ویژگی چهره و خوشه‌بندی خودکار چهره‌های مشابه با استفاده از الگوریتم DBSCAN استفاده می‌کند.

### موارد استفاده

- 📸 **سازماندهی آلبوم عکس** - گروه‌بندی خودکار عکس‌ها بر اساس شخص
- 🏢 **مدیریت حضور و غیاب** - شناسایی افراد از عکس‌های گروهی
- 🔍 **جستجوی چهره** - یافتن همه عکس‌های یک فرد خاص در یک مجموعه بزرگ
- 📁 **بایگانی دیجیتال** - سازماندهی تصاویر بایگانی بر اساس هر فرد

### نحوه کار

1. کاربر تصاویر متعدد را از طریق رابط وب آپلود می‌کند
2. برنامه با استفاده از RetinaFace تمام چهره‌ها را تشخیص می‌دهد
3. FaceNet512 بردارهای ویژگی 512 بعدی (جاسازی) را برای هر چهره استخراج می‌کند
4. DBSCAN چهره‌های مشابه را بر اساس فاصله کسینوسی خوشه‌بندی می‌کند
5. کاربر به هر خوشه (شخص) نام می‌دهد
6. تصاویر در پوشه‌هایی به نام هر شخص سازماندهی می‌شوند
7. کاربر خروجی سازماندهی شده را به صورت فایل ZIP دانلود می‌کند

## 🚀 نصب

```bash
git clone https://github.com/yourusername/face-clustering-app.git
cd face-clustering-app
```

مرحله 2: ایجاد محیط مجازی (توصیه می‌شود)

Windows:

```bash
python -m venv venv

```

Linux / macOS:

```bash
python3 -m venv venv
source venv/bin/activate
```

```bash
pip install -r requirements.txt
```

· DeepFace (تشخیص چهره)

به آدرس زیر بروید:

📖 راهنمای استفاده

1. آپلود تصاویر

· روی ناحیه آپلود کلیک کنید یا تصاویر را روی آن بکشید و رها کنید
· یک یا چند فایل تصویری انتخاب کنید (فرمت‌های پشتیبانی شده: JPG، PNG، JPEG، BMP، GIF)
· فایل‌های انتخاب شده در زیر ناحیه آپلود نمایش داده می‌شوند
· روی دکمه "شروع پردازش" کلیک کنید

2. مشاهده نتایج خوشه‌بندی

· سرور تصاویر را پردازش کرده و همه چهره‌ها را تشخیص می‌دهد
· چهره‌ها به طور خودکار در خوشه‌ها گروه‌بندی می‌شوند (یک خوشه برای هر شخص)
· برای هر خوشه، 3 نمونه تصویر چهره نمایش داده می‌شود
· تعداد کل چهره‌ها و خوشه‌ها در بخش آمار نشان داده می‌شود

3. نام‌گذاری هر شخص

· برای هر خوشه، نام شخص را در قسمت متن وارد کنید
· مثال نام‌ها: "رضا"، "محمد"، "سارا"
· قبل از ادامه مطمئن شوید همه خوشه‌ها نامگذاری شده‌اند

4. ذخیره و سازماندهی

· روی دکمه "ذخیره نام‌ها" کلیک کنید
· سرور پوشه‌هایی در index/person_name/ ایجاد می‌کند
· همه تصاویر حاوی آن شخص در پوشه مربوطه کپی می‌شوند (انتقال داده نمی‌شوند)

5. دانلود خروجی

· روی دکمه "دانلود خروجی (ZIP)" کلیک کنید
· یک فایل ZIP شامل همه پوشه‌های سازماندهی شده دانلود می‌شود
· ساختار ZIP: face_clusters.zip → index/person_name/image_files

6. شروع مجدد (اختیاری)

· برای حذف همه تصاویر آپلود شده و خروجی روی "پاک کردن همه" کلیک کنید
· یا پس از دانلود برای شروع یک جلسه جدید روی "راه‌اندازی مجدد" کلیک کنید
· نیازی به راه‌اندازی مجدد سرور نیست

تغییر پورت سرور

```python
if __name__ == '__main__':
```

تنظیم پارامترهای DBSCAN

در app.py حدود خط 81 ویرایش کنید:

```python
clustering = DBSCAN(
    eps=0.45,           # حداکثر فاصله بین دو نمونه
    min_samples=1,      # حداقل نمونه برای تشکیل یک خوشه
    metric='cosine'     # معیار فاصله
).fit(embeddings_norm)
```

پارامتر توضیحات مقادیر پیشنهادی
eps حداکثر فاصله بین دو نمونه برای قرار گرفتن در یک همسایگی 0.3 - 0.6
min_samples حداقل تعداد نمونه در یک همسایگی برای یک نقطه به عنوان نقطه هسته 1 (برای تصاویر تکی از هر شخص)
metric معیار فاصله استفاده شده برای خوشه‌بندی 'cosine' یا 'euclidean'

راهنمای تنظیم:

· بسیاری از خوشه‌ها (بیش از حد تقسیم شده): eps را افزایش دهید (مثلاً 0.5)
· خوشه‌های بسیار کم (تقسیم ناقص): eps را کاهش دهید (مثلاً 0.35)
· یک شخص در چندین خوشه: eps را افزایش دهید
· افراد مختلف در یک خوشه: eps را کاهش دهید

تغییر مدل تشخیص چهره

```python
DeepFace.represent(

    detector_backend='retinaface',
    enforce_detection=False,
```

2. قبل از آپلود، اندازه تصاویر را کاهش دهید
3. RAM سیستم را افزایش دهید یا از دستگاهی با حافظه بیشتر استفاده کنید
4. برنامه‌های دیگر را ببندید تا RAM آزاد شود

مشکل: هیچ چهره‌ای تشخیص داده نشد

نشانه: خطای "هیچ چهره‌ای برای خوشه‌بندی یافت نشد" یا نتایج خالی.

علل و راه حل‌ها:

· تصاویر تار: از عکس‌های واضح‌تر و با کیفیت بالاتر استفاده کنید
· چهره‌های کوچک: مطمئن شوید چهره‌ها حداقل 80x80 پیکسل هستند
· نمای نیمرخ/جانبی: در صورت امکان از عکس‌های رو به جلو استفاده کنید
· نور ضعیف: مطمئن شوید چهره‌ها به خوبی روشن و قابل مشاهده هستند
· عینک آفتابی/ماسک: در صورت امکان موانع را حذف کنید

اشکال‌زدایی: بررسی کنید که چهره‌ها تشخیص داده می‌شوند:

```python
from deepface import DeepFace
result = DeepFace.detectFace("test.jpg")
```

مشکل: خوشه‌بندی نادرست (افراد اشتباه گروه‌بندی شده‌اند)

نشانه: افراد مختلف در یک خوشه قرار دارند، یا یک فرد در چند خوشه تقسیم شده است.

راه حل‌ها:

1. پارامتر eps DBSCAN را تنظیم کنید:
   · تقسیم شدن یک فرد: eps را افزایش دهید (مثلاً 0.5)
   · ادغام افراد مختلف: eps را کاهش دهید (مثلاً 0.35)
2. از یک مدل دقیق‌تر استفاده کنید:
   ```python
   model_name='ArcFace'  # دقیق‌تر از FaceNet512
   ```
3. از کیفیت تصویر ثابت اطمینان حاصل کنید: نور و زوایای مشابه دقت را بهبود می‌بخشد

مشکل: پورت از قبل در حال استفاده است

نشانه: OSError: [Errno 98] Address already in use

راه حل‌ها:

گزینه 1: پورت را در app.py تغییر دهید:

```python
app.run(port=8080)  # از پورت متفاوت استفاده کنید
```

گزینه 2: فرآیند استفاده کننده از پورت 5000 را متوقف کنید:

Windows:

```bash
netstat -ano | findstr :5000
taskkill /PID <PID> /F
```

Linux/macOS:

```bash
lsof -i :5000
kill -9 <PID>
```
